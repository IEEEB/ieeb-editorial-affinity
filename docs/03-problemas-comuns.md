# Problemas comuns

| Sintoma | Causa | O que fazer |
|---|---|---|
| O Claude diz que não acha o Affinity | Affinity fechado ou MCP desligado | Abra o Affinity e ligue em **Configurações → Protocolo de contexto do modelo**; reinicie o app Claude |
| "Arquivo não encontrado" numa imagem | O Affinity da Microsoft Store só lê a Área de Trabalho | Ponha a pasta de trabalho da obra na Área de Trabalho |
| Erro `CREATE_FILE_ERROR` ao salvar | O script não consegue fazer o 1º "Salvar como" | Salve você pelo menu; depois o Claude salva sozinho |
| O Claude não consegue abrir o `.af` | Caminho com acento (ex.: "Área de Trabalho") | Abra o arquivo você mesmo pelo menu; o Claude o encontra aberto |
| O Affinity fechou de repente | Muitas imagens grandes num script só | Peça para montar em lotes de 4 a 5 páginas e salvar entre os lotes |
| O Affinity só bipa e não aceita clique | Um diálogo ficou escondido atrás da janela | Alt+Tab ou clique no ícone do Affinity na barra de tarefas |
| Texto saiu em outra fonte, ou o Affinity não acha a Nunito | A fonte não está na pasta **Fontes** do Windows | Arraste os arquivos da fonte para a pasta Fontes (Windows + R, `shell:fonts`), feche e abra o Affinity; peça ao Claude para conferir |
| Última linha do texto sumiu | O quadro de texto ficou pequeno | Peça para aumentar o quadro ou diminuir o texto |
| Tem espaço grande entre os parágrafos | O estilo padrão do Affinity põe 12 pt depois do parágrafo | A biblioteca já zera isso; se for script antigo, peça para zerar |
| Exportação "deu erro de tempo" | O conector tem tempo limite, mas a exportação continua | Espere o arquivo aparecer na pasta antes de exportar de novo |
| Não consigo substituir o PDF | O PDF está aberto em outro programa | Feche o leitor de PDF ou exporte com outro nome (v2) |
| Imagem borrada no PDF | Resolução abaixo de 300 dpi | Amplie a imagem (Magnific ou outro) e troque no documento |
| O Claude não sabe as regras do IEEB | A aba Code foi aberta em outra pasta | Abra a aba Code na pasta `Documentos\ieeb-editorial-affinity` |
| "Atualizar a pasta" deu erro | A pasta foi mexida à mão | Peça ao Claude para baixar de novo do zero (as obras estão no OneDrive, nada se perde) |
| Duas pessoas mexeram no mesmo `.af` | O Affinity não junta edições | Combine quem está com a obra; a outra pessoa espera ou trabalha em cópia |
